# お繋ぎ申請 集計ダッシュボード

会員一覧スプレッドシートの「お繋ぎ申請」タブを集計し、「集計ダッシュボード」タブに書き出す Google Apps Script。

## できること
- 状態別件数・成立率（成立÷(成立+見送り)）
- 月別の申請数・成立数
- 大量申請の検知（1人1日20件以上）
- 要対応リスト：①確認中なのに未打診 ②受付のまま3日以上 ③承諾のまま ④打診後14日返事なし ⑤申請から21日以上未完了
- 「打診停止」「大畑さん」メモ付きの行は静観扱いで除外

## 安全性
- 元データは読むだけ。書き込むのは「集計ダッシュボード」タブのみ。

## 導入（5分）
1. スプレッドシート → 拡張機能 → Apps Script
2. `集計ダッシュボード.gs` の中身を貼り付けて保存
3. 関数 `updateDashboard` を選んで ▶実行（初回のみ権限の許可）
4. 毎朝自動にするなら `installDailyTrigger` を1回実行

## しきい値の変更
ファイル冒頭の `CONFIG` の数字を変えるだけ。
